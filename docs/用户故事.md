## EPIC-01 课表导入
覆盖「外部 Excel 变成本地课表」全过程。

### US-001 导入 Excel 课表
- 用户故事：作为学生，我想在外部把课表整理成 `.xlsx` 后导入，以便不配置 AI 识图也能让工具知道我每周的课。
- 优先级：高
- 关联需求：FR-001、FR-002
- 验收标准：
  - Given 我有符合模板的 `.xlsx` When 我点「选择 Excel 文件 (.xlsx)」导入 Then 工具显示「解析成功：课程 N 条、节次 M 条」并列出每门课的星期/大节/课程名/教室/周次规则
  - Given 文件缺少工作表、表头错误或字段非法 When 我导入它 Then 工具显示「导入被拦截，共 N 处问题（旧课表未改动）」，逐条给出「工作表 第N行 [字段]：原因」
  - Given 我选择旧 `.xls` 文件 When 我导入它 Then 工具提示只支持 `.xlsx`，请先另存为 `.xlsx`
  - Given 我无法取得 Excel When 需要录入课表 Then 仍可通过「手动录入 / 编辑课程」完整录入

### US-002 核对并确认课表
- 用户故事：作为学生，我想核对解析结果后再确认导入，以便提醒不会用错课表。
- 优先级：高
- 关联需求：FR-003、FR-004
- 验收标准：
  - Given 解析结果已展示 When 我点「确认导入」 Then 新课表原子替换旧课表并写入 `data/schedule.json`，页面提示「已导入并保存」
  - Given 解析结果已展示 When 我点「取消」 Then 旧课表保持不变，页面提示「已取消，旧课表保持不变」
  - Given 课表尚未点确认 When 到达某课程提醒时刻 Then 仍按原课表提醒（未确认的解析结果不生效）

### US-003 更新课表
- 用户故事：作为学生，我想在换课或换学期时重新导入 Excel 或手动修改课表，以便提醒始终准确。
- 优先级：中
- 关联需求：FR-008
- 验收标准：
  - Given 课表已存在 When 我重新导入新 Excel 并确认 Then 旧课表被整份替换（含新节次时间轴），后续提醒按新课表执行
  - Given 课表已存在 When 我手动新增/修改/删除某门课并保存 Then 只改动该课程，其余课程不变，写回 `data/schedule.json`
  - Given 我刚改过课表 When 下一次提醒到来 Then 去重记录已清空，按新课表重新计算
  - Given 我当前没有任何节次时间 When 我打开手动录入 Then 工具自动补 6 个大节的默认时间（08:10 起）供我直接录入

### US-009 周次/单双周配置
- 用户故事：作为学生，我想为课程配置周次/单双周规则和学期起止日期，以便只在本课真正上课的周收到提醒。
- 优先级：高
- 关联需求：FR-009
- 验收标准：
  - Given 某课周次规则写「单周」 When 当前教学周为双周 Then 当天不为该课提醒，本周课表该格灰色标注「本周不上」
  - Given 某课周次规则写「1-16」 When 当前为第 17 周 Then 当天不为该课提醒
  - Given 课程周次规则留空 When 未做任何配置 Then 默认每周生效（按第 1 周处理）
  - Given 我把首周周一选成非周一 When 我点「保存设置」 Then 工具提示「学期第一周必须从周一开始」且不保存
  - Given 周次规则写成「1-80」 When 我保存或导入 Then 工具判定为非法（周次范围限 1~60）

## EPIC-02 定时提醒
覆盖「到点就叫你」的核心价值。

### US-004 课前提醒（提前量可配置，默认 40 分钟）
- 用户故事：作为学生，我想在每个有课的大节开始前一段时间（全局可配置，默认 40 分钟）收到提醒卡片和提示音，以便从容收拾去上课。
- 优先级：高
- 关联需求：FR-006、FR-014
- 验收标准：
  - Given 提前量为默认 40 分钟且今天有课 When 距上课还有 40 分钟 Then 屏幕右下角弹出提醒卡片并播放提示音，标题「课前提醒：课程名」，正文含上课时间、地点、第几大节及起止时间
  - Given 系统关闭了通知或开启了专注助手 When 到达提醒时刻 Then 卡片照样显示（自绘窗口不经过系统通知通道）
  - Given 卡片已弹出 When 6 秒内我没有操作 Then 卡片淡出消失；鼠标停在卡片上则暂停倒计时，移开重新计时
  - Given 同一课程同一大节 When 该提醒已弹出 Then 当天不再重复弹（含重启程序后）
  - Given 我把提前量改为 60 分钟并保存 When 下一节课临近 Then 在上课前 60 分钟提醒
  - Given 提前量超出 1~180 When 我点「保存设置」 Then 工具提示范围并要求重填，不保存
  - Given 周日晚同一门课连第一至第四大节 When 按「每大节各提醒」策略 Then 在 07:30、09:20、12:50、14:40 各提醒一次
  - Given 同时有两节课临近 When 两张卡片都在屏幕右下角 Then 卡片自下而上堆叠，关掉一张其余自动重排

### US-005 窗口最小化与退出
- 用户故事：作为学生，我想点 X 时程序不要退出（否则就不提醒了），并有一个明确的地方可以真正关掉它。
- 优先级：高
- 关联需求：FR-005
- 验收标准：
  - Given 程序正在运行 When 我点窗口右上角 X Then 窗口最小化到任务栏，程序不退出、提醒照常触发，托盘区不出现图标
  - Given 窗口已最小化 When 我点任务栏按钮或再次双击程序 Then 窗口回到前台（再次双击不会开出第二个进程）
  - Given 我要彻底关闭程序 When 我进「设置」页点「退出课表提醒」 Then 弹出二次确认，确认后进程结束、不再提醒
  - Given 我重启了电脑 When 电脑开机完成 Then 程序不会自行启动（v0.1.7 已撤销开机自启）

## EPIC-03 课表查看

### US-006 查看今日课程
- 用户故事：作为学生，我想随时查看今天有什么课、还剩什么课，以便安排自己的时间。
- 优先级：中
- 关联需求：FR-007
- 验收标准：
  - Given 课表已确认 When 我打开「今日课表」页 Then 看到当天课程按上课时间排列，每行含时间范围、课程名、教室
  - Given 某节课已经开始 When 我看列表 Then 该项前标「【已过】」
  - Given 我突然改了系统时间或课表 When 我点「刷新」 Then 列表立即按最新时间重算

### US-008 查看整周课表
- 用户故事：作为学生，我想一眼看到这一周七天各有什么课，以便提前安排学习和生活。
- 优先级：中
- 关联需求：FR-013
- 验收标准：
  - Given 课表已确认 When 我打开程序 Then 默认停在「本周课表」页，看到 7 列（周一~周日，带日期）× 节次行数的网格，每格有课程名与教室
  - Given 今天是周四 And 第 2 大节正在进行 When 我看课表 Then 周四整列有浅色底纹，第 2 大节周四这格有加粗描边（每分钟自动刷新）
  - Given 某门课本周不生效（如单周课在双周） When 我看该格 Then 仍能看到课程名，下方灰色标注「本周不上」
  - Given 我想看下周安排 When 我点「下一周」 Then 表格切到下周日期，标题标「（非本周）」，底纹与描边消失；点「本周」回到当前周

### US-010 点击提醒卡片查看今日剩余
- 用户故事：作为学生，我想点击提醒卡片直接看到今天剩余的课程，以便快速确认接下来的安排。
- 优先级：中
- 关联需求：FR-010
- 验收标准：
  - Given 今天还有未开始的课 When 我点击提醒卡片 Then 主窗口切到「今日课表」并弹出今日剩余课程列表（时间/课程名/教室）
  - Given 今日课程已全部结束 When 我点击提醒卡片 Then 提示「今天没有剩余课程了。」

### US-007 错过补提醒（已裁决：本期不做）
- 用户故事：作为学生，我想在开机后看到今天错过的提醒，以便知道错过了什么。
- 优先级：已裁决——本期不做（2026-11-21 用户确认错过不补发），仅留档备查。

## EPIC-04 程序形态与设置

### US-011 查看版本与数据位置
- 用户故事：作为学生，我想确认程序版本和课表数据存在哪里，以便备份或换电脑时不出错。
- 优先级：低
- 关联需求：FR-016
- 验收标准：
  - Given 我打开程序 When 我切到「关于」页 Then 看到「课表提醒 v0.1.7」、便携与离线说明，以及实际数据目录路径
  - Given 我按关于页显示的路径去找 When 我打开该目录 Then 能看到 `schedule.json`、`settings.json`、`state.json`、`logs/`、`backup/`

### US-012 保存设置与测试提醒
- 用户故事：作为学生，我想一次配好提前量、提示音和学期日期，并能立刻验证提醒效果，以便第一节课就不会错过。
- 优先级：高
- 关联需求：FR-015
- 验收标准：
  - Given 我在设置页把提前量改为 60、关掉提示音 When 我点「保存设置」 Then 提示「已保存」并写入 `data/settings.json`
  - Given 我填了首周周一和结束日期 When 我保存 Then 设置页显示「当前为第 N 教学周（学期共 M 周）」或「学期尚未开始/已结束」
  - Given 我想确认提醒长什么样 When 我点「测试提醒」 Then 立刻弹一张卡片（优先用今天还没上的下一节课，其次今天第一门，今天没课则用示例课程「高等数学 / 教三-201」）
  - Given 我点「退出课表提醒」 When 我在确认框选「是」 Then 程序退出，不再产生提醒
