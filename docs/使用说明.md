# 课表提醒 · 使用说明

> 文档版本：v1.1 ｜ 对应程序：v0.1.7 ｜ 2026-11-22
> 📖 [返回 README](../README.md)｜[需求文档](需求文档.md)｜[技术方案](技术方案.md)

## 一、获取程序

程序源码在 GitHub 仓库 **CourseReminder**，编译好的程序只以 **Release 附件** 形式发布：

1. 打开仓库右侧的 **Releases**，下载 `CourseReminder-v0.1.7-win-x64.zip`。
2. 解压到任意目录（例如 `D:\Tools\CourseReminder\`），**不要**直接在压缩包里双击运行。
3. 双击 `CourseReminder.exe` 启动。

程序只有这一个**免安装文件夹版**；旧的自包含单文件版（v0.1.4）已删除，避免拿错版本。仓库不提交二进制文件，`dist/` 是本地构建产物，已由 `.gitignore` 排除。

## 二、运行环境

- Windows 10 / 11（x64）。
- 需要 **.NET 8 Desktop Runtime**（x64）；未安装时启动会提示缺少运行时，按提示到微软官网下载安装即可。

## 三、文件构成

| 文件 | 说明 |
|---|---|
| `CourseReminder.exe` | 主程序，双击运行 |
| `CourseReminder.dll` / `.deps.json` / `.runtimeconfig.json` | 程序本体与配置，**不可删除** |
| `CourseReminder.pdb` | 调试符号，排查崩溃时有用，可保留 |
| `使用说明.md` | 本文件 |

## 四、数据存放位置

程序运行后会在 **exe 同级** 自动创建 `data/`：

```
data/
├── schedule.json        # 已导入的课表
├── settings.json        # 提前分钟数、提示音、学期起止日期
├── state.json           # 已发送提醒的去重记录（保留 60 天）
├── backup/              # 每次写入前的旧文件备份
└── logs/YYYY-MM-DD.log  # 运行日志，排查问题先看这里
```

> 业务数据全部在程序目录内，**不写 C 盘**。整个文件夹可直接拷贝备份/换机。

## 五、首次使用（5 步）

1. 双击 `CourseReminder.exe`。
2. 打开「设置」页，填 **学期第一周的周一日期**（必须是周一；它决定单双周/周次范围从哪天算起），再填学期结束日期，保存。
3. 打开「导入课表」页 → 选择课表 `.xlsx` → 程序列出待导入课程与错误行 → 核对后点「确认导入」。
   - 导入失败**不会**覆盖已有课表。
   - 没有现成 Excel 也行：点「手动录入 / 编辑课程」可逐门新增、修改、删除课程，与导入共用同一份 `data/schedule.json`。
   - 模板见仓库 [`templates/课表模板.xlsx`](../templates/课表模板.xlsx)，格式说明见本文第六节。
4. 回「本周课表」页确认整周显示正常；「设置」页可核对提前分钟数与学期信息。
5. 点窗口右上角 **X 不会退出程序**，而是**最小化到任务栏**（任务栏按钮一直在，点一下就回来），提醒继续运行。**要真正退出，只有一条路：打开主窗口 →「设置」页 → 点「退出课表提醒」。**

### 五个页面

| 页面 | 用途 |
|---|---|
| **本周课表** | 默认首页。7 天 × 各节次的整周表格，每格显示课程名与教室 |
| 今日课表 | 今天要上的课，按时间排序，已过的标「【已过】」 |
| 导入课表 | 换课时导入 Excel；也可点「手动录入 / 编辑课程」逐门维护 |
| 设置 | 提前分钟数、提示音、学期首周周一与结束日期、退出程序 |
| 关于 | 版本号、项目说明与许可信息 |

**本周课表怎么看：**

- 列 = 周一~周日（列头带日期如 `周一 11/23`），行 = 你课表里实际的大节数，左侧标「第N大节 + 起止时间」。
- **今天那一列**是浅蓝底纹；**当前正在上的那一节**有蓝色加粗描边（每分钟自动刷新）。
- 灰色小字 **「本周不上」**＝这门课本周（按单双周/周次规则）不上课，比如单周课在双周就会这样显示。
- 顶部按钮：**上一周 / 本周 / 下一周**；不在本周时，标题会标「（非本周）」，底纹与描边不显示。

## 六、Excel 模板格式

需要两个工作表（模板另附「填写说明」表，仅作注释，导入时忽略）：

**「课程」**（表头放在前 10 个非空行内的任意一行都能识别，建议第 1 行）

| 星期 | 大节 | 课程名 | 教室 | 教师 | 周次规则 |
|---|---|---|---|---|---|
| 一 | 1 | 高等数学 | 教三-201 | 张老师 | 1-16 |

**「节次时间」**

| 大节 | 开始时间 | 结束时间 |
|---|---|---|
| 1 | 08:10 | 09:40 |

填写规则：

- 星期：`一`~`日` 或 `1`~`7`。
- 大节：正整数，且必须能在「节次时间」表里找到。
- 课程名、教室：必填。
- 周次规则：`每周` / `单周` / `双周` / `1-16` / `1,3,5`；留空视为每周；周次范围 1~60。
- 时间：`HH:mm`，结束必须晚于开始。
- 同一星期同一大节只能有一门课（单双周互补可共存）。
- 只支持 `.xlsx`；旧 `.xls` 请先另存为 `.xlsx`。
- 表格里的行号/单元格引用缺失（部分工具导出的 xlsx 会这样）时程序会自动按顺序补齐，不会整行丢掉。

## 七、提醒规则

- 每节课 **开始前 N 分钟** 在屏幕右下角弹**提醒卡片** + 提示音，N 在设置页改（默认 40，可设 1~180）。
- 连堂（同一大节连上）**每个大节各提醒一次**，不合并。
- 程序没运行或电脑关机时**错过不补发**。
- 点击提醒卡片 → 跳到「今日课表」看剩余课程。
- 同时有多个提醒时，卡片从屏幕右下角向上堆叠；关掉一张，其余自动重新排好位置。
- 同一节课只提醒一次（`state.json` 去重，跨重启有效，记录保留 60 天）。
- **学期开始前、结束后不再提醒**；学期结束按「设置」里的结束日期自动停止。
- 提前时间落在前一天时（如提前 3 小时、课程在早上），会在前一天照常提醒。
- 电脑睡眠唤醒、系统时间被修改后会自动重新扫描一次提醒。

## 八、常见问题

- **点了 X 之后程序去哪了**：程序没有退出，只是缩到了任务栏（任务栏按钮还在，点一下就回来），提醒照常运行。要彻底关掉它：打开主窗口 →「设置」页 →「退出课表提醒」。
- **托盘里找不到图标**：v0.1.7 起**程序不再使用系统托盘**，没有托盘图标也不需要它。所有操作都在主窗口里：点 X 缩到任务栏、要退出用「设置」页的按钮。
- **它会开机自己启动吗**：不会，v0.1.7 已去掉开机自启。需要的话自己把 `CourseReminder.exe` 的快捷方式放进「启动」文件夹（Win+R 输入 `shell:startup`）。
- **想立刻看看提醒长什么样**：打开「设置」页，点 **「测试提醒」** 按钮，会马上弹一张提醒卡片（今天有课就用今天的课当样本，没课则用「示例课程：高等数学」）。
- **没有弹通知**：先点「测试提醒」验证；仍无反应就看 `data/logs/今天的.log`；Windows 开了「专注助手/勿扰」会静默气泡，需在系统设置放行。
- **提示缺少 .NET**：装 .NET 8 Desktop Runtime（x64）。
- **重复导入同一份 Excel**：整体替换课表，不影响已发送记录。
- **双击程序没反应**：说明有旧的 `CourseReminder` 进程还在后台占着（常见于异常结束），到任务管理器结束它再打开；新版会弹提示告诉你这一步。也可以先到任务栏找找有没有已经缩起来的窗口。
- **数据文件坏了/写盘失败**：每次保存前会在 `data/backup/` 留一份旧文件；备份失败只会记日志，不会阻止本次保存。
- **程序报「遇到未处理的错误」**：同样的错误 5 分钟内只弹一次框，详细信息在 `data/logs/`。
- **换电脑**：整个程序文件夹拷过去，重新确认一次学期首周周一。

## 九、已知限制

- 提醒卡片是程序自己画的窗口（不依赖 Windows 通知中心），所以就算关了系统通知、开了专注助手也照样能显示；代价是它只覆盖屏幕右下角一块，不进入通知历史。
- 卡片默认 6 秒后自动消失；鼠标移上去会暂停倒计时。
- 不内置课表图片识别，课表需先在外部转成模板 `.xlsx`，或手动在「手动录入 / 编辑课程」里逐门填。
- 手动录入与 Excel 导入是同一份数据：手动加课后如果又导入 Excel，会整份替换（导入前会先预览确认）。
