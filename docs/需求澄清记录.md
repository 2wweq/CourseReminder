## 二、对设计的启示
1. 作息表无需单独提供：节次起止时间已印在课表上，识别时一并提取（推翻 2026-11-21「需用户提供作息表」的假设）。
2. 周日全天连堂（同一门课连 4 大节：上午块 08:10-11:30、下午块 13:30-16:50）→ 提醒频次是关键设计点（用户已裁决：每大节各提醒）。
3. 周六无课、周日有课 → 提醒引擎必须覆盖周末，不能只做工作日。
4. 课程名截断 → 人工核对环节需支持编辑补全（FR-003）。
5. 识别源是教务系统网页截图（非拍照）→ 识别准确率高，「AI 视觉识别 + 人工核对」路线已实测可行。
6. 提醒时刻换算示例：第一大节 08:10 上课、提前 40 分钟 → 07:30 提醒；第三大节 13:30 → 12:50。

## 三、决策记录
- 2026-11-21：提前量全局可配置（默认 40 分钟）；错过不补发；本期仅电脑端。
- 2026-11-22：连堂提醒=每个大节各提醒一次，不做合并；单双周=有周次/单双周限制（具体规则与学期起止日期在配置时提供，不阻塞定稿）；通知交互=点击通知可查看今日剩余课程。

## 四、v0.1.5 / v0.1.6 落地补充（2026-11-22，开发回填，非新需求）
1. 首周周一的输入必须是真正的周一（原只校验「有日期」），否则整学期周次错位、单双周反相 → 设置页保存时强校验。
2. 提前量实际范围定为 **1~180 分钟**（原文档只写"可配置，默认 40"）；提前时刻落在前一天时按前一天日期调度。
3. 提醒去重记录（`state.json`）**只保留 60 天**，每天扫描时顺带清理，避免无限增长。
4. 学期开始前与结束后：不显示课程、不产生提醒（原文档只写"按学期起止日期判断当周生效"）。
5. 同一星期同一大节的冲突判定从"只比第一门"改为"周次规则是否重叠"——单周/双周互补课合法共存，其余重叠即拦截。
6. 周次规则的单值与范围上限统一为 **60 周**；`单周/双周/奇数周/偶数周/每周/1-16/1,3,5` 为合法写法。
7. 表头不再要求固定在「课程」表第 1 行：前 10 个非空行内自动识别表头（应对上方有标题行的模板）。
8. 手动录入课表落地为最小版：新增 / 修改 / 删除课程，与 Excel 导入共用 `data/schedule.json`；无课表时自动补一套默认 6 大节时间（08:10 起），录完可再导 Excel 整份替换。
9. 提醒卡片堆叠改为"自下而上、关一张其余重排"；程序未处理异常 5 分钟内只弹一次框，避免反复弹框盖住界面。
10. 开机自启状态不再写进 `settings.json`（以注册表与设置页显示的自启命令为准），避免文件里的值与实际不一致。
## 五、v0.1.7 功能取舍（2026-11-22，用户决定）

- **撤销开机自启**：用户原话「算了。舍弃开机自启以及隐藏托盘这两个功能」。FR-005 的「开机自动启动」自 v0.1.7 起不再提供，代码与本机注册表写入全部移除。
- **撤销托盘常驻**：程序不再创建任何系统托盘图标/右键菜单/气泡（连图标一起删）。原因：本机系统托盘始终不登记本程序的图标（HKCU\Control Panel\NotifyIconSettings 80 条记录无一条命中，同一 exe 换路径后即正常），排查性价比低。
- **窗口与退出行为**：点 X 一律最小化到任务栏（不退出、提醒继续）；**唯一退出入口**是主窗口「设置」页的「退出课表提醒」按钮（带二次确认）。
- 补充：若日后需要开机自启，由用户自行把快捷方式放进 shell:startup，程序不再代为管理。

## 六、发布形态与文档校订（2026-11-22，v0.1.7 交付回填）

- **发布形态定了**：只保留一个**免安装文件夹版**（本地构建输出到 `dist/`，对外以 GitHub Release 分发）——`CourseReminder.exe` + `CourseReminder.dll` + `.deps.json` + `.runtimeconfig.json` + `使用说明.md`，运行时自动生成 `data/`；目标机需 **.NET 8 Desktop Runtime（x64）**。旧的自包含单文件版（v0.1.4）与旧发布目录已删除。
- **主窗口 5 个页签**：本周课表（默认首页）、今日课表、导入课表、设置、**关于**（新增；显示 v0.1.7、便携/离线说明与实际数据目录）。
- **技术栈落定**：C# / .NET 8 + WPF，**零第三方 NuGet 依赖**；Excel 由自研 `Excel/XlsxReader.cs` 直读 OOXML（彻底放弃 ClosedXML），提醒用自绘 `Views/ToastWindow` + `SystemSounds.Asterisk`。
- **确认不自启、不托盘**：与第五节一致；点 X 只最小化到任务栏，唯一退出入口是设置页「退出课表提醒」（二次确认）；`Settings` 模型不再有自启字段。
- **文档校订**：以发布包与实际源码为基准，统一修正 `需求文档.md`（v2.2 → v3.0，撤掉 FR-005 开机自启、改为窗口最小化与退出，补 FR-015 设置页 / FR-016 关于页 / NFR-008 运行环境 / NFR-009 单实例）、`用户故事.md`（v2.0 → v3.0，US-005 改为最小化与退出，新增 US-011 关于页、US-012 设置与测试提醒）、`技术方案.md`（v0.3 → v1.0，删除 ClosedXML/原生 Toast/AUMID/托盘/自启/单文件发布）、`编码实施计划.md`（v0.2 → v1.0，文件结构与路线按实际落地）。
