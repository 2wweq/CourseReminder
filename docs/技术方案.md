## 1. 已确认的实现边界
- 独立 Windows 桌面应用（WPF），不是 DSH 插件，日常运行不要求启动 DSH 或浏览器。
- 课表照片转 Excel 在外部通过 AI 或人工完成；应用只导入约定模板的 `.xlsx`，不内置视觉识别。
- Excel 导入、课表查看和提醒均完全离线，不要求安装 Office，不需要模型 API 或 API Key。
- 只用「一个主窗口 + 5 个页签」：本周课表 / 今日课表 / 导入课表 / 设置 / 关于。
- 提醒为**自绘卡片窗口**，不经过 Windows 通知中心（不注册 AUMID、不调用 WinRT Toast）。
- **不提供开机自启、不使用系统托盘**（v0.1.7 撤销）；点 X 只最小化到任务栏，唯一退出入口是设置页按钮。
- 绿色便携：全部数据只写在程序所在文件夹的 `data/` 内，不写 C 盘用户目录或系统其他位置。
- 每个有课大节单独提醒，默认提前 40 分钟（可设 1~180）；电脑关机、睡眠或程序未运行时错过的不补发。

## 2. 技术栈与实际选型结论
**C# / .NET 8（`net8.0-windows`）+ WPF + 零第三方 NuGet 依赖。**（已实施）

| 关注点 | 最终做法 | 说明 |
|---|---|---|
| Excel 读取 | 自研 `Excel/XlsxReader.cs` 直读 OOXML | `System.IO.Compression` 解 zip + 读 `xl/workbook.xml`、`sharedStrings.xml`、`worksheets/sheet*.xml`；不用 ClosedXML，避免额外依赖与远端包下载 |
| 提醒展示 | 自绘 `Views/ToastWindow` + `Notifications/ToastNotifier` | 无边框置顶窗口，右下角堆叠，6 秒淡出；不依赖系统通知通道 |
| 提示音 | `System.Media.SystemSounds.Asterisk` | 受设置页「提醒时播放提示音」开关控制 |
| 弹窗与系统事件 | WPF + `UseWindowsForms=true` | `OpenFileDialog` 选文件、`SystemEvents.PowerModeChanged/TimeChanged` 感知唤醒与改时间 |
| 存储 | `System.Text.Json` + 临时文件原子替换 + 备份 | 见第 5 节 |
| 单实例 | 命名互斥锁 + 轮询激活已有窗口（`Sys/SingleInstance.cs`） | 见第 8 节 |
| 发布 | 框架依赖的文件夹版，需 .NET 8 Desktop Runtime x64 | 见第 2.1 节 |

选择理由：
1. 面向 Windows 单一平台，WPF 足够覆盖表格视图、编辑器与自绘卡片。
2. 零第三方依赖：离线环境可直接 `dotnet build`/`publish`，不怕私有源或网络限制。
3. 自绘卡片不受系统通知开关、专注助手影响，满足「必须真正可见」的验收要求。
4. 便携模式 + 框架依赖发布，发布包体积小（`CourseReminder.exe` 约 148 KB + `.dll` 约 96 KB），拷走即用。

### 2.1 发布形态（v0.1.7 定稿）
- 发布命令：`dotnet publish -c Release -r win-x64 --self-contained false -o dist`。
- 产物：`dist/` 下的 `CourseReminder.exe`、`CourseReminder.dll`、`CourseReminder.pdb`、`CourseReminder.deps.json`、`CourseReminder.runtimeconfig.json`，外加运行时自动生成的 `data/`。

## 4. Excel 模板与导入设计
### 4.1 约定模板
工作表 1：`课程`

| 星期 | 大节 | 课程名 | 教室 | 教师 | 周次规则 |
|---|---|---|---|---|---|
| 一 | 2 | 高等数学 | A101 | 张老师 | 每周 |
| 日 | 1 | 大学物理 | B202 | 可选 | 1-16 |

- 星期：`一`~`日`，也接受 `1`~`7`、`星期一`、`天`。
- 大节：正整数，必须能在「节次时间」表中找到同名大节。
- 课程名、教室：必填；教师、周次规则：可选（教师列缺失也允许）。
- 周次规则：留空或「每周」=每周；「单周/奇数周」=单周；「双周/偶数周」=双周；支持 `1-16`、`1,3,5`、`1-16,18`；周次 1~60，超范围报错。

工作表 2：`节次时间`

| 大节 | 开始时间 | 结束时间 |
|---|---|---|
| 1 | 08:10 | 09:40 |
| 2 | 10:00 | 11:30 |

学期第一周周一和学期结束日期在设置页配置，不写入 Excel。

### 4.2 导入、校验与确认（实现细节）
1. 只接受 `.xlsx`；选到 `.xls` 直接报「只支持 .xlsx；旧版 .xls 请先另存为 .xlsx」。
2. 必需工作表：`课程`、`节次时间`，缺一即拦截。
3. 表头不要求在第 1 行：在「前 10 个非空行」内按命中列数选最佳行，应对上方有标题行的模板。
4. xlsx 里行号/单元格引用缺失（部分工具导出会这样）时按顺序补齐，不整行丢弃。
5. 逐行校验：星期可识别、大节为正整数且在节次表存在、课程名/教室非空、时间可解析（`HH:mm`、`8:10`、`08:10:00`、Excel 小数比例均可）、结束晚于开始、节次表内大节不重复、同一星期同一大节的周次规则不重叠（单双周互补允许共存）、周次规则可识别、至少一行有效数据。
6. 错误串统一格式：`工作表 第N行 [字段]：原因`；界面显示「导入被拦截，共 N 处问题（旧课表未改动）」并逐条列出。
7. 解析结果进入 `ScheduleService.PendingImport` 暂存，不直接落盘；点「确认导入」才原子替换并清空去重记录；点「取消」只丢弃暂存。
8. 无 Excel 时可「手动录入 / 编辑课程」逐门增删改，写同一份 `schedule.json`；无任何节次时自动补默认 6 大节。

## 5. 本地数据
**便携模式：所有数据在程序所在文件夹的 `data/` 子目录，禁止写入 C 盘用户目录或系统其他位置。**

下面是发布包（`dist/` 或 Release 解压目录）的结构：

```text
<程序文件夹>/
├── CourseReminder.exe
├── CourseReminder.dll / .deps.json / .runtimeconfig.json   # 不可删
├── 使用说明.md
└── data/
    ├── schedule.json      # 课表（课程列表 + 节次时间轴）
    ├── settings.json      # 提前分钟数、提示音、学期起止日期
    ├── state.json         # 已发送提醒的去重键（保留 60 天）
    ├── logs/YYYY-MM-DD.log
    └── backup/            # 写入前的旧文件备份 + 损坏文件备份
```

实现要点：
1. 数据根 = `AppContext.BaseDirectory` + `data`（`Data/PortablePaths.cs`），不读环境变量、不回落用户目录；自检模式可用 `UseTestRoot` 指向测试目录。
2. 启动时若无 `data/` 自动创建；创建失败抛中文异常，提示把程序移到可写目录（如 D 盘非 Program Files 路径），不静默改用 C 盘。
3. `JsonStore.Load`：文件不存在或解析失败返回默认值；损坏文件先备份为 `backup/<name>-corrupt-yyyyMMddHHmmss.json`。
4. `JsonStore.Save`：写 `path.tmp`（`FileStream` + `Flush(true)` 真正落盘）→ 原文件存在则先复制到 `backup/<文件名>.bak`（失败只记日志）→ `File.Move(tmp, path, overwrite)`。
5. `settings.json` 只有 `AdvanceMinutes`（默认 40）、`PlaySound`（默认 true）、`Semester{FirstMonday, EndDate}`；**不自启字段**。启动项的注册表写入已随 v0.1.7 全部删除。
6. 去重键只保留 60 天：每天首次扫描时 `ReminderState.Trim` 按 `yyyyMMdd` 字符串序过滤。
7. 卸载即删文件夹，无残留；备份由用户整体拷贝文件夹完成。

## 6. 提醒调度
1. 用 `DispatcherTimer` **每分钟扫描一次**（Interval = 1 分钟），启动即扫一次；鲁棒应对睡眠唤醒与系统时间跳变，满足误差 ≤ 1 分钟。
2. `ReminderCalculator.Evaluate(schedule, now, advance)`：
   - 只扫描「今天」与「明天」两天（覆盖提前量跨日的情况）。
   - 当天教学周 `< 1`（学期未开始/已结束/未配置为 1）时跳过。
   - `now >= 大节开始时间` → 跳过（错过不补发）。
   - `dueAt = 大节开始 − 提前量`；`now < dueAt` → 跳过（未到点）。
   - 去重键已在 `state.json` → 跳过。
3. 触发后：弹卡片 → `State.TryMarkSent(key)` → 立即保存 `state.json`，保证重启后不重复。
4. 去重键 = `yyyyMMdd + "_" + 课程Id + "_" + 大节`（`Course.KeyFor(day)`）。
5. 周次判定按「上课当天」日期算，不按提醒发送日；提前时刻落在前一天时按前一天实际日期调度。
6. 系统唤醒（`PowerModeChanged.Resume`）与系统时间变化（`TimeChanged`）后立即强制重扫一次，不等下一个整分钟。
7. 每分钟扫描同时负责界面刷新：日期变化或当前大节变化时刷新「今日课表」与「本周课表」。

## 7. 提醒卡片与点击交互
- 形态：`Views/ToastWindow.xaml`，无边框、置顶、不占任务栏、不抢焦点；自绘圆角卡片，标题 + 三行正文。
- 文案（`ToastNotifier.BuildToastText`）：标题「课前提醒：<课程名>」；正文「今天（周X）HH:mm 上课 / 地点：<教室> / 节次：第 N 大节（hh:mm–hh:mm）」。
- 布局：距工作区右下角 `Edge=20`、卡片间距 `Gap=10`；按「新的在下、旧的往上」叠放；任意一张关闭后 `Relayout` 让其余回落补位。
- 生命周期：`LifeSeconds=6`；`MouseEnter` 暂停计时、`MouseLeave` 重新计 6 秒；默认 6 秒后 180 ms 淡出并关闭。
- 动画注意：`OnLoaded` 里只做定位与计时，淡入动画用 `Dispatcher.BeginInvoke(..., DispatcherPriority.Background)` 延后启动，避免布局阶段改 `Opacity` 导致渲染死锁。
- 点击：卡片关闭 + 回调 `ToastNotifier.ShowTodayRequested` → 主窗口切到「今日课表」→ `MessageBox` 显示「今日剩余课程：」逐行「时间范围 课程名 @ 教室」；无课时「今天没有剩余课程了。」
- 提示音：`SystemSounds.Asterisk.Play()`，受设置页开关控制。
- 设置页「测试提醒」：优先用「今天还没上的下一节课」，否则今天第一门，今天没课则用内置示例（示例课程：高等数学 / 教三-201 / 第 1 大节 08:10）。
- 不使用系统通知：不注册 AUMID、不调用 WinRT/CommunityToolkit，因此不进入通知历史，也不受系统通知开关影响。

## 8. 窗口、退出与单实例
- 点 X：`Window_Closing` 中若 `_exiting` 为 false 则 `e.Cancel = true` 并 `WindowState = Minimized`——只缩到任务栏，不隐藏到托盘、不退出。
- 退出：只有设置页「退出课表提醒」→ `MessageBox` 二次确认 → `ExitApp()`（停扫描定时器、释放通知器、`Close()`、`Application.Current.Shutdown()`）。
- 单实例：`SingleInstance.TryAcquireFirst()`（命名互斥锁）失败时 `SignalExistingInstance()` 唤起已有实例（`Show` → `Normal` → `Activate` → 短暂 `Topmost` 抖动 → `Focus`），随后自身退出；唤起失败则提示去任务栏找窗口或在任务管理器结束旧进程。激活广播由 `StartActivationListener` 监听。
- 未处理异常：`DispatcherUnhandledException` 记日志后 `Handled = true`，同样错误 5 分钟内只弹一次「程序遇到未处理的错误：…」。
- **无开机自启**：不写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，设置页无自启开关；需要时用户自行把快捷方式放进 `shell:startup`。
- **无托盘**：不创建 `NotifyIcon`，无托盘菜单与托盘气泡（源码中已无 `TrayIcon`/`AutoStart`）。

## 9. 核心数据结构（真实字段）
```text
Semester        ：FirstMonday?(DateTime?)、EndDate?(DateTime?)、IsConfigured
TimeSlot        ：Slot(int)、Start(TimeSpan)、End(TimeSpan)
Course          ：Id(string, GUID)、Weekday(1~7)、Slot、Name、Room、Teacher、WeekRuleText、
                  WeekRule（由 WeekRuleText 派生，JsonIgnore，不落盘）、KeyFor(day)
WeekRule        ：Parse(text) → Every/Odd/Even/Weeks{集合}；IsActive(week)；Overlaps(其他)
Settings        ：AdvanceMinutes(默认 40)、PlaySound(默认 true)、Semester
ReminderState   ：SentKeys(List<string>)、TryMarkSent(key)、Trim(now)（保留 60 天）
ImportError     ：工作表名、行号、字段、原因；ToString() = "工作表 第N行 [字段]：原因"
```

`data/schedule.json` 顶层为 `{ Courses: [...], Slots: [...] }`（由 `ScheduleService.Current` 承载）。

## 10. 异常与边界
- Excel 无法读取、模板不符或字段不完整：报具体位置，不生成提醒、不覆盖旧课表。
- 暂存未确认：不参与提醒。
- 周六无课：不生成提醒；周日连堂：按每个大节分别生成提醒。
- 提前时间落在前一天：按前一天实际日期调度，不默认丢弃。
- 同一天跨单双周边界：按上课当天日期计算周次。
- 关机/睡眠错过：不补发；程序崩溃后重启：只恢复未来提醒（已发送键仍在 `state.json`）。
- 学期未配置：`TeachingWeek` 按第 1 周处理，页面提示「未配置学期」；学期外：`TeachingWeek` 返回 0，不返回课程、不提醒。
- 数据目录不可写：启动/保存时抛中文异常并提示挪到可写目录，不静默改路径。
- 系统通知被禁用、专注助手开启：卡片照样显示（自绘窗口，不经过通知通道）。

## 11. 验证手段
- 内置自检 `--selftest <测试目录> <报告文件>`（`SelfTest.cs`）：周次规则单测、Excel 用例逐份解析、业务层集成（导入落盘、星期匹配、提醒时刻、错过不补发、去重），失败项计入报告（自检所需的 Excel 用例不随仓库发布）。
- 界面探针 `--uiprobe <报告文件>`：无界面环境下 dump 本周课表结构（列/行数、表头、每格文本）。
- 卡片探针 `--toastprobe <报告文件>`：验证卡片文案与叠放定位。
- `--minimized`：启动即最小化，便于验证「点 X 只最小化」与单实例唤起。
- 手工验收：见 `需求文档.md` 第 7 节；实机项包括重启后不自启、点 X 最小化、二次启动切前台、断网且未装 Office 导入、整文件夹复制到另一盘符可用、`%LocalAppData%`/`%AppData%` 无残留。

## 12. 已知限制
- 卡片是自绘窗口，只覆盖右下角一块，不进通知历史；系统通知中心里看不到记录。
- 卡片固定 6 秒自动消失（悬停暂停），暂不可配置时长。
- 不内置课表图片识别；课表需外部转 `.xlsx` 或手动录入。
- 手动录入与 Excel 导入共用同一份数据，导入会整份替换。
- 文件夹版需 .NET 8 Desktop Runtime，目标机没装会提示缺运行时。
