## 1. 目标与范围
实现 Windows 独立桌面小程序 CourseReminder：导入约定模板 `.xlsx` → 校验 → 核对确认 → 便携存储 → 每个有课大节提前提醒（自绘卡片 + 提示音）→ 点击卡片看今日剩余课程。本期只做电脑端、只支持 `.xlsx`、完全离线、数据全部落在 exe 同级 `data/`，不写 C 盘。**不含**开机自启与系统托盘（v0.1.7 撤销）。

## 2. 工程配置
- 目标框架：`net8.0-windows`，`UseWPF=true`、`UseWindowsForms=true`（选文件对话框与系统事件），`Nullable/ImplicitUsings` 开启，`Version 0.1.7`。
- 程序集名 `CourseReminder`，输出 `WinExe`。
- **NuGet：零第三方依赖**（不引 ClosedXML，Excel 由自研 `Excel/XlsxReader.cs` 直读 OOXML）。
- 发布：`dotnet publish -c Release -r win-x64 --self-contained false` → 文件夹版（exe + dll + deps.json + runtimeconfig.json），目标机需 .NET 8 Desktop Runtime x64。
- RID 不写进 csproj，保证日常构建离线可用、不触发远端运行时包下载。
- 语言：代码标识符英文，注释、日志、UI 文案全中文。

## 4. 模块职责
| 模块 | 职责 | 关键点 |
|---|---|---|
| Models | 数据结构 | 与 JSON 对齐；`WeekRuleText` 存原文、`WeekRule` 由原文派生且 `JsonIgnore` |
| PortablePaths | 数据根目录 | `AppContext.BaseDirectory + "data"`；创建失败报中文错并提示挪到可写目录 |
| JsonStore | 存储 | `tmp` 写入 + `Flush(true)` → 备份 `.bak` → `File.Move(overwrite)`；损坏文件另存 `-corrupt-<时间>.json` |
| ScheduleExcelParser + XlsxReader | 导入 | 扩展名/工作表/表头（前 10 非空行）/逐行字段校验；错误定位「工作表+行号+字段+原因」；缺行号自动补齐 |
| ScheduleService | 业务 | 暂存预览 → 确认后原子替换并清空去重；手动增删改；`TeachingWeek`/`TotalWeeks`/`CoursesOn`/`TodayRemaining`/`WeekMatrix` |
| ReminderCalculator | 调度计算 | 只扫今天与明天；教学周、未到点、已上课、已发送四类跳过；去重键 `yyyyMMdd_Id_Slot` |
| ToastNotifier + ToastWindow | 通知 | 文案组装、提示音 `SystemSounds.Asterisk`、卡片堆叠与 6 秒淡出、点击回调切今日页 |
| SingleInstance | 单实例 | 命名互斥；二次启动唤起已有窗口（失败给中文提示） |
| CourseEditorWindow | 手动录入 | 星期/大节下拉 + 课程名/教室/教师/周次规则；`WeekRule.IsValidText` 校验；无节次自动补默认 6 大节 |
| SelfTest | 自检 | 周次规则单测 + Excel 用例 + 业务集成，输出文本报告 |

## 5. 核心数据文件
- `data/schedule.json`：课程列表 + 节次时间轴（含周次规则原文）。
- `data/settings.json`：提前量（默认 40）、提示音开关、学期首周周一与结束日期（无自启字段）。
- `data/state.json`：已发送提醒去重键（保留 60 天）。
- `data/logs/YYYY-MM-DD.log`、`data/backup/`：日志与写入前备份/损坏文件备份。

## 6. 提醒调度实现要点
1. 「每 1 分钟扫描一次」而非精确定时器：每分钟取当前时间，找出应触发未触发的提醒，鲁棒应对睡眠唤醒与系统时间变化（误差 ≤ 1 分钟）。
2. 触发后先去重（`TryMarkSent`）再落盘 `state.json`，重启不重复；已错过的直接跳过不补发。
3. 周次判定按「上课当天」计算；提前时刻落在前一天时按前一天日期调度（扫描覆盖今天与明天两天）。
4. 启动、睡眠唤醒（`PowerModeChanged.Resume`）、系统时间变化（`TimeChanged`）、课表/设置变更后立即强制重扫。
5. 每分钟顺带刷新界面：日期或当前大节变化时刷新今日列表与周视图（本周课表底纹/描边随时间移动）。

## 9. 通知选型的演进（结论已定）
需求是「提前提醒 + 提示音 + 点击查看更多」。三条路线：
- 路线 A：注册 AUMID + WinRT/CommunityToolkit Toast——真原生卡片，但要处理 COM 激活与单实例联动，成本高、易受系统通知开关/专注助手影响。
- 路线 B：`NotifyIcon.ShowBalloonTip` + `SystemSounds`——实现最简，但仍依赖托盘图标与系统气泡通道；本机托盘不登记本程序图标，气泡时有时无。
- **路线 C（最终采用）**：自绘无边框卡片窗口 `ToastWindow` + `SystemSounds.Asterisk`——不依赖系统通知通道与托盘，系统关通知/开专注助手也能显示；点击回调就是普通事件，最可靠。
已确认：v0.1.7 采用路线 C，同时删除托盘图标与开机自启。

## 11. 风险与注意
- 开发调试期 `AppContext.BaseDirectory` 落在 `bin\Debug\net8.0-windows\`，`data/` 会建在那里；发布后即 exe 同级，属预期现象。
- 目标机未装 .NET 8 Desktop Runtime 会直接报缺运行时；须在使用说明中前置提示（已写）。
- `CourseReminder.csproj` 注释已在仓库版同步修正为「`--self-contained false` 文件夹版、输出 `dist/`」，不再保留 v0.1.4 的单文件发布旧说法。
- 卡片为自绘窗口，不进通知历史；若将来需要通知中心记录，须回到路线 A 重新评估。
- 手动录入与导入共用同一份数据：先手动加课再导入 Excel 会被整份替换（界面已有预览确认）。
